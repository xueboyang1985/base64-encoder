FAQ

Is Base64 the same as encryption?

No. Base64 is encoding, not encryption. Anyone can decode Base64 instantly. Never use Base64 to protect sensitive data.

Does Base64 increase file size?

Yes. Base64 increases data size by approximately 33%. Every 3 bytes becomes 4 ASCII characters.

What is the free limit?

Free version supports files up to 10KB. PRO users get unlimited file sizes.
