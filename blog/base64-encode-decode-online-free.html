What is Base64?

Base64 is an encoding scheme that represents binary data in an ASCII string format. It uses 64 characters (A-Z, a-z, 0-9, +, /) to represent data. The = character is used for padding. Base64 is not encryption — it's encoding, which means it can be easily reversed.

Common Use Cases

  • Embedding images in HTML: Use data URLs to include images directly in web pages
  • Email attachments (MIME): Binary attachments are Base64-encoded for transmission
  • JSON data: Store binary data as strings in JSON APIs
  • Data URLs: Embed small assets directly in CSS or HTML
  • Basic authentication: Encode username:password for HTTP Basic Auth headers

How Browser-Based Base64 Works

JavaScript provides built-in functions for Base64 encoding:

  • btoa(): Encode a string to Base64 (binary to ASCII)
  • atob(): Decode Base64 back to a string (ASCII to binary)
  • FileReader.readAsDataURL(): Convert files to Base64 data URLs
